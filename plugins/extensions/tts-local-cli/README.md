# TTS Local CLI

将文本转换为语音，使用设置中选择的本地语音模型或明确配置的在线服务。

本地模式需要先安装相应模型和音色。在线模式需配置有效服务地址；需要认证时配置凭据，不使用公共服务或其他模型自动兜底。

在线合成使用 `openai-speech-http` 的 JSON 请求和有界二进制音频响应。音色须明确选择预置音色；既有 `speakerVoice` 保留预置音色含义，不自动补入音色。未知协议与已移除字段拒绝执行，工具选择与回复朗读分别配置。

本包保留原生 `tts-local-cli` 插件、provider 和本地 CLI 合同，启停策略同时约束本地及在线分支。在线分支需要宿主提供匹配的原生 SDK、已注册的 OpenAI 兼容 Speech 适配器和已准备的 SecretRef；缺失适配器或协议不受支持时直接失败。在线请求限制于所配服务，拒绝重定向及不确定请求重试；停止播放不代表远端合成已中止。

分发时须提供所需运行依赖和许可证；模型及服务可用性仍需分别确认。来源文件标识见 [upstream-source.json](upstream-source.json)，本地实现和许可证随包提供。
