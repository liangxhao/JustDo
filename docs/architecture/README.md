## 维护归属

- 架构说明机制和跨域契约，功能文档说明具体用户流程；同一业务规则在功能 owner 维护，架构只保留影响边界的摘要及链接。
- Team、Workflow、浏览器和模型的规则分别在功能目录维护；插件表结构、事务及资源保护仍在存储文档说明，不因业务代码独立分发而省略恢复边界。
- 通用设计与版本证据分开。依赖和运行包版本引用 `package.json`、锁文件及运行时清单；补丁清单和移除条件只在当前补丁总账维护。
- 新增持久字段、协议或恢复行为时更新所属专题；验证限制随该专题维护，不把阶段报告、旧通过数量或已完成计划作为第二份现状。
