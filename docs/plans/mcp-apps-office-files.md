# MCP Apps Office 文件能力（待实现）

2026-10-18 用户要求先记录；2026-10-19 追加实施源文件编辑保存。剩余待办不代表当前插件已经支持。

## 当前范围

Univer 插件仅接入表格模块，文件树支持 `.xlsx`、`.csv`、`.tsv` 预览和源文件编辑保存；
工作簿 JSON 可手动导入。2026-10-19 按用户要求去掉“编辑副本”，加入源文件 ETag 冲突检查、
原件备份和安全原子保存。XLSX 保留原包，仅更新单元格/基础格式，结构及布局改动拒绝写回。
当前合同见独立插件 README 和[宿主文件资源约定](../features/chat/mcp-apps.md)。PPTX、DOCX 尚未接入。

## 待办

- **XLSX 源文件结构编辑**：在保留图片、图表、外部引用与未知 OOXML 部件的前提下，
  扩展行列/布局和工作表增删、重排、重命名的写回能力；当前拒绝这些保存，不能使用完整转换覆盖原包。
- **PPTX 离线预览**：接入幻灯片渲染和 Office 文件转换，先满足工作区文件点击预览。
  DOCX 作为同类扩展候选单独评估。Univer 的整体产品能力不能视为当前插件能力；
  官方 PPTX 导入方案使用 `@univerjs-pro/slides-exchange-client` 和配套转换后端，
  需核实目标版本、授权及完整离线部署条件，再确定采用官方方案或其他本地转换实现。

## 约束与验收

- 实现留在独立可选插件中，不内置到主程序安装包，不增加 OpenClaw patch。
- 保留当前工作区边界、原生会话身份、生命周期及文件读写授权；只读快照不代表已获得写回权限。
- 转换、字体、脚本和其他资源均在本地或公司内网提供，整个使用过程不得依赖公网服务。
- 原文件保存验证外部修改冲突、权限撤销、写入失败、备份恢复和重开结果；
  未知写入结果不得盲目重试，未保存编辑不得被自动重载覆盖。
- PPTX 预览验证多页、布局、图片、图表及字体替换，并在断网环境验证加载和重开；
  DOCX 如纳入实施，另行验证分页、表格和图片。预览与完整编辑分别验收。

大文件扩容仍单独记录在 [MCP Apps 大表格扩容](mcp-apps-large-spreadsheets.md)，本次不实施。
