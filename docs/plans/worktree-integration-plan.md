# Worktree 剩余验收

状态：入口与管理已接入，真实 Gateway、模型和设备环境仍待验收。现行行为、权限、原生配置及限制统一见[Worktree](../features/workspace/worktree.md)。本页只保留未完成的验收，不保留实施前缺口表。

## 真实运行链路

使用锁定的最终运行时、有提交的临时 Git 仓库和获准使用的模型，记录原生会话、运行及检出身份。测试资源通过原生生命周期清理。

- [ ] 开启入口后，新会话勾选 Worktree，原生准备成功才提交首轮；取消或创建失败不在源目录执行。
- [ ] 用户要求独立任务时，模型创建同助手的原生可见 Worktree 子会话，产品只采用有可信父子与目录身份的记录。
- [ ] 创建后、Gateway 重启后与应用重启后均能去重发现、打开、继续、停止，并回到父会话。
- [ ] Review、文件预览、审批、计划产物与浏览器使用实际检出目录，源项目仅用于归属；父子文件互不覆盖。
- [ ] 创建失败、父会话删除、原生删除或快照失败、请求结果未知时，保留可追踪状态；worktreePreserved 不误报已清理。
- [ ] 原生闲置回收后可按保留规则恢复；恢复、移除与清理遵守 operator 权限，不由产品直接删除 Git 目录或分支。

## 设置与平台

- [ ] 存储目录与加速设置保存后区分已保存/已应用；版本冲突、断线和超时不自动重放写请求。
- [ ] 启动、无模型及登录/退出配置同步保留原生设置；修改目录只影响新分配，旧记录与恢复仍用原路径。
- [ ] Windows 中文及空格路径验证完整链路；macOS/Linux 分别记录真实运行结果，不由 Windows 或单元测试代替。
- [ ] guarded/workspace/full 与 ask 接入不扩大权限；不可表达权限、跨助手会话及 Worktree 复制/分叉保持现行限制。
