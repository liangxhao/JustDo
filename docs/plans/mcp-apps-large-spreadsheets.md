# MCP Apps 大表格扩容（待实现）

2026-10-18 记录：先修复历史 App 卡片和 XLSX 预览的不可用问题，扩容稍后实施。
当前限制仍为源文件 10 MiB、转换后 Univer 工作簿 8 MiB、每表 5000 行/100 列。

## 候选方案

- 以 50 MiB 源文件作为下一档压测目标，未经验证不作为已支持容量。
- 插件内分片传递和读写文档，避免 Base64 放大后超过 Gateway 单条消息约 25 MiB 的限制。
- 后台线程解析 XLSX，提供进度、取消和有界内存使用，避免阻塞界面。
- 同时调整转换后容量、行列和实际单元格总量限制；不能只提高压缩文件大小。
- 根据稀疏/密集数据、公式、样式、多工作表的实测结果确定可编辑规模；更大数据可评估按工作表/区域只读加载。
- 保留当前会话工作区授权、原生身份及生命周期检查；实现留在可选插件中，不增加 OpenClaw patch 或公网依赖。

## 验收

覆盖 10–50 MiB 的真实 XLSX、解压膨胀、取消、内存峰值、首次呈现、滚动与编辑响应、
分片中断及过期、保存/重开/导出，以及越界/软硬链接/会话切换/权限撤销。
未保存编辑不能在自动恢复或重连中被静默替换。
