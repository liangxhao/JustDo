# 启动与历史升级的现场验收

实现契约见[启动分流与历史会话升级](../features/app/startup-and-history-upgrade.md)。
已用隔离历史副本验证原生导入、缓存转换、标题映射、父子关联、续聊及重启持久性；
实现包含三类启动判定、持久阶段恢复和共用柔光汇聚展示。

发布前仍需以下真实环境证据：

- Windows 新用户安装与当前 SQLite 用户覆盖安装；普通覆盖升级保留现有设置且不显示初始化。
- 发布 JSONL 用户覆盖安装，以真实企业账号重新初始化，恢复后从主会话继续，检查附件。
- 在客户反馈问题的电脑覆盖安装，收集真实错误日志并确认无需手动“重新加载引导界面”。
- 在阻断公共网络、无缓存的干净安装环境验证全部资源随包可用。
- 在备份、隔离、初始化、原生导入、映射写入与最终检查处退出/重启，验证阶段恢复。
- 安装路径包含中文和空格；低速磁盘及大量历史；真实安装包中的窗口交接与动画表现。
- 磁盘不足、Windows 文件占用/权限不足时查看具体处理建议，手动关闭占用进程后重启重试；确认未完成备份不被当作成功备份使用。
- 迁移结果页显示会话/正文缺失/目录需重选数量，备份按钮打开正确目录，点击进入后揭幕；等待与揭幕期间的错误继续阻断首页交互。
- 历史工作目录为空、被移走或不存在仍完成迁移；首次打开沿用当前新会话模型/权限默认配置，后续自选项重开后保持。
