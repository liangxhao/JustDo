# 交互式回答：剩余设计与验收

现行用户流程与限制维护在 [交互式回答](../features/chat/interactive-answers.md)，
原生权限和窗口契约维护在架构。本页只保留真实模型、发布平台的未完成验收，以及
依赖新原生合约的候选能力；已完成的原型、阶段计划和审查流水由 Git 追溯。

## 发布前检查

- 从当前分支独立准备应用与锁定的 OpenClaw 运行时，不对共享 junction 原地重建。
  运行时准备、ABI 与安装流程沿用 [开发指南](../development.md)；个人 Gateway
  的配置、凭据、历史不参与隔离测试。
- 在正常应用会话中显式启用 Interactive UI，核对实际工具 schema，而不是仅看
  插件源文件或模拟模型通过。用下方矩阵记录真实模型的形式选择、首次可见耗时、
  一次成功率、工具次数、数字和交互，不读取或提交用户原始 transcript/log。
- 对签名安装包检查 ASAR/HTTP 主页面与工作区加载、受限 preload、首条提交、
  实时/历史卡片、重启恢复、禁用与失败操作。独立 Electron/ASAR 探针的旧环境
  结果不能替代当前安装包；Windows/macOS/Linux 分别记录实际覆盖与剩余问题。
- 工作区侧聊检查卡片在拆出/收回、移除/重新挂载、主题与尺寸变化后的加载和草稿，
  保留 dev 的窗口控制、菜单、宠物位置与终端状态。设备及多显示器验收另见
  [独立工作区](../features/workspace/detached-workspace.md)。
- 隔离场景检查 33 份文档的原生 32 份保留上限、断线/迟到结果、只读会话、转录
  修改与跨会话建议失效。不得为模拟故障删除个人文档，不自动补发不确定执行。

重复验证入口为 `scripts/test/interactive-ui/verify-runtime.mjs` 和
`verify-gateway.mjs`（通用组件加 `--ui`，保留上限加 `--retention`）；脚本使用临时
原生状态和合成 provider，只验证注册、工具、认证与历史合约，不计作真实模型效果。
正式行为测试与打包回归位于 `tests/scripts/interactive-ui/`，应结合受影响宿主、
发送、投影和草稿领域测试，结果注明当前提交及环境，不累加重叠测试次数。

## 操作与记录

从本分支独立准备应用/运行时，在扩展设置显式启用 Interactive UI，确认实际工具
公布 `interactive-answer` / `scenario-explorer`。各提示词使用新会话、相同模型配置；在 840px
和 312px 卡片外框宽度分别验证明暗主题与键盘操作，同时记录内部可用宽度（当前
2px 边框对应 838/310px 内部宽度，勿用聊天容器宽度替代）。记录模型 ID、首次可见界面耗时
（从发送起）、工具次数与通过/失败类别。缺少工具声明时应降级，文件预览不算内联。

先判断形式是否适合问题。清晰的文字可能比多余组件更好；原生 HTML 是合理自由布局
路径，但需独立核对数字、主题和交互，不能仅凭加载成功评为通过。不改变权限开关。

## 提示词与通过标准

| 用例          | 可接受的形式                   | 通过标准                                               |
| ------------- | ------------------------------ | ------------------------------------------------------ |
| 1. 简单算术   | 文字                           | 不生成多余组件，答案正确                               |
| 2. 方案比较   | compare 或清晰表格             | 指标对应、选择可带回草稿、不编造推荐依据               |
| 3. 搜索排序   | table                          | 全量搜索、数字排序、分页不丢数据，空结果清楚           |
| 4. 数据趋势   | chart 与数据表                 | 同源数字；负值、零线、图例和长标签可读                 |
| 5. 收集需求   | form                           | 必填/范围正确，非法值不能继续，输入焦点稳定            |
| 6. 分步说明   | steps 或文字                   | 阅读顺序清楚，可键盘展开，内容完整                     |
| 7. 固定测算   | scenario-explorer              | 固定公式 18 天/75,600 元，假设明确                     |
| 8. 多组件探索 | 合理的 interactive-answer 组合 | 切换保留输入，草稿反映修改，不声称永久保存或任务已执行 |

### 1. 简单结果

> 20 × 15 是多少？只需要告诉我结果。

期望 300，文字即可。

### 2. 方案比较

> 根据示例比较，并让我选择后继续分析：A，成本 90，12 天；B，成本 110，9 天；
> C，成本 105，11 天。只比较给出的成本与工期，不要编造质量或风险评分。

期望两项统一指标；选择 B 后草稿反映 B，不自动发送。

### 3. 搜索与数字排序

> 做一个可以搜索、按工时排序的表格。示例数据：界面 8、存储 12、测试 20、文档 3、
> 打包 10、主题 6、权限 18、集成 15。让我筛选“测试”，再返回完整列表。

期望搜索全量 8 行，数字顺序 3/6/8/10/12/15/18/20，分页不丢第 6–8 行。

### 4. 正负数据

> 用交互图表显示示例变化并提供数字表：第一周 -4，第二周 0，第三周 3，第四周 7。
> 单位小时。我想开关系列查看趋势，不要把负数变成零。

期望图表与表格一致，关闭所有系列有空态、恢复数值不变。

### 5. 输入表单

> 收集项目需求：名称必填，工时必填且为 1–200 的数字，优先级可选低/中/高，是否
> 需要导出是勾选项。名称和工时先留空，优先级默认中，导出默认不勾选。填完先让我
> 审阅，再带回输入框发送。

期望空必填、0、201 不能继续，错误关联字段；有效输入反映在草稿。

### 6. 分步说明

> 用逐步展开的方式解释“准备数据 → 检查数据 → 绘制图表”，每步说明目的、输入与
> 输出。不要调用外部服务，内容简短。

期望结构可读，键盘可展开，没有自动执行。

### 7. 固定公式

> 用现有固定测算组件探索示例：工作量 448 小时，每人每天 700 元，预算 80,000 元，
> 目标 21 个工作日，初始 6 人、每天专注 6 小时。说明未考虑假期、依赖与并行限制；
> 不在文字里复述未经校验的估算数字。

公式 `ceil(448 / (6 * 6 * .82 * (1 - .025 * 5)))` 得到 18 个工作日，
成本 `18 * 6 * 700 = 75,600`。8 人 × 6 小时应为 14 天、78,400 元。

### 8. 组合与后续

> 用一个界面组合方案比较、趋势和需求表单：A（成本 90，12 天）与 B（成本 110，
> 9 天）；趋势第一周 2、第二周 5、第三周 4；表单收集名称和优先级。切换组件后
> 保留本次选择，再带回草稿继续讨论，不自动提交。

期望选 B、修改表单、切到图表后输入仍在；草稿有各组件身份及实际选择。刷新回到
默认值，与临时状态说明一致，不宣称已有跨重启保存。

## 故障与极限交互

故障仅在隔离测试会话制造，不删除个人文档：缺失文档、资源加载失败、运行时错误
分别验证重新加载与用户发起重建。重建只生成建议，切会话或重连后旧建议不能加入
新草稿；加载失败不猜测是否被淘汰、不转发原始日志。

正式行为测试构造 8 组件、100 行、12 字段、长 Unicode/引号/换行及负/零图表。
浏览器验证底部动作可达、无多余垂直滚动、完整选择可复制；最终草稿 ≤3600 UTF-16，
省略明确且后续组件不被静默丢弃。

## 依赖原生合约的候选能力

### 跨重启的组件状态

原生先定义 document/session 身份、版本与授权、可保存的组件值 schema、读写及
并发修订，以及删除/淘汰生命周期。恢复必须匹配原文档和版本，隐藏页面不得持续
写入；如果由扩展拥有状态，仍需证明原生会话/文档授权，不能接受模型任意 docId。
只保存受校验的选择值，不保存 HTML/transcript，也不使用 localStorage 或产品 KV
模拟缺失的文档状态接口。合约明确后再定实施范围和验收，当前仍在重载时恢复默认值。

### 真正的渐进呈现

原生需要有界 begin/append-or-replace/complete/cancel 事件，绑定 run/tool/session/
document/revision，并明确序号、取消、并发和终态存储。只展示完整的已校验结构块，
不执行半截 HTML/JS；迟到事件拒绝，终态由 Gateway 保存并能从历史恢复。
当前 `canvas.document.view` 返回完整文档；加载占位不等于流式组件，不从助手文本
或工具参数增量伪造授权。上游契约或版本升级需独立审核，本范围不增加运行时补丁。

### MCP Apps 独立轨道

先核对 locked runtime 的原生 `mcp.app.*` 路径、UI resource/MIME、app-visible tools、
active-run effective policy、用户 opt-in、lease 与重启只读重建；iframe 不能获得
MCP server 凭据。资源、上下文更新和动作授权分别测试，不复用 inline widget
私有 prompt 桥代执行，也不把 dashboard grant 发给内联组件。完成专门设计和真实
验收前，不公告该 capability。

这些候选不作为现行产品支持承诺，也不推断 ChatGPT 已有相同状态/授权接口。产品
方向参考原始 [OpenAI 发布](https://openai.com/zh-Hans-CN/index/gpt-6-for-everyone/)，
本产品依赖的事实以锁定原生注册和实际调用为准，不接入或复制私有界面编译器。

每项验收完成后，把仍有效的行为和限制更新到对应功能/架构说明，并从本页移除
已完成内容；不保留新的阶段审查流水。
