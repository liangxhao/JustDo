# v2026.8.5 更新说明

## 当前版本变更

- 新增 Windows 自动更新：应用启动后自动检查更新，并可在“设置 → 帮助”中手动检查、查看下载进度及重启安装。
- 使用 Generic 静态更新源生成并校验 `latest.yml`，支持安装包哈希、大小、更新说明和 blockmap 完整性检查。
- 固化 Windows Generic HTTPS 更新地址，并在 CI 中校验安装包、更新清单和差分更新产物。
- 优化更新安装退出流程，在安装前安全停止任务运行服务、扩展宿主和定时任务并关闭 SQLite。
- 自动更新仅对通过 NSIS 正式安装的 Windows 应用启用，开发环境和解压目录会显示为不支持。
- 调整内置模型服务默认地址，提高本地服务配置兼容性。
