# v2026.8.11 更新说明

## 主要更新

- 新增浏览器模式设置，可在隔离浏览器与用户 Chrome 之间切换，并提供配置引导、连接测试和状态刷新。
- 新增持续目标执行与安全终止控制，提升长时间任务的可靠性。
- 优化最近会话、分组和侧边栏交互；会话权限可持久保存并即时生效。
- 完善会话历史保留、消息恢复和上下文压缩异常后的恢复能力。
- 提高内置 skills 更新、删除及文件占用处理的可靠性，并完善定时任务的原生 cron 操作。
- 改进模型请求分类、子任务会话标识和父子会话关联，提升统计与审计准确性。
- 增加客户信息启动及周期同步；同步失败不阻塞应用启动。
- 优化开发启动流程和 Windows 离线环境，并进一步减小安装包体积。
