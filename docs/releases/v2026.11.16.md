# 更新说明

## 对话与工作区

- **可以在已有对话里直接和助手语音交谈。** 配置并启用兼容的在线语音对话模型后，点击输入框里的电话图标即可开始。助手会接着之前的话题聊，语音内容也会同步显示为文字。交谈时可以控制麦克风和扬声器，随时结束。
- **部分执行错误可以自动重试。** 遇到工具反复报错、上下文超限等可恢复的问题时，助手会在原会话里尝试继续。桌面、Chrome 扩展、命令行和外部客户端都支持这项功能。重试次数可在设置中调整，也可以关闭。
- 使用 **Git Worktree** 开始新对话时，如果所选仓库还没有提交，可以先选定文件，确认创建首次本地提交，再继续发送。会话列表会用分支图标标出 Worktree 会话，设置里可以查看托管目录对应的分支、来源项目和最近活动时间。
- 从父会话摘要打开**子智能体详情**，可以查看聊天记录。带输入框的子会话还可以直接追问。子任务列表暂时加载失败时，会保留上次成功加载的内容，并提供重试入口。
- MCP 工具返回的图片会显示在对应的工具步骤下方。展开处理过程即可查看，双击图片可放大。
- 在会话列表右键选择「导出对话」，可以把仍可读取的历史消息按时间顺序保存为 OpenAI 兼容的 JSON 文件。长对话中尚未滚动加载的消息也会一并导出。
- 修复了聊天里带括号的网址有时只能点开一部分、同一工具失败提示重复显示，以及部分任务交接后工具不可用的问题。应用恢复会话时也更少出现卡在发送前的情况。

## 浏览器与网页接入

- **Chrome 扩展侧栏按标签页打开。** 切回原标签页时，草稿还在。侧栏里可以选择工作目录，也能直接回答助手的提问。回复、思考过程和工具执行详情的排版也做了调整。
- **业务网页可以直接发起对话。** 第一次点击已接入网页的对话按钮时，侧栏会请你确认网站和授权范围，无需提前登记。允许连接后，这次消息会先填入输入框，检查后再发送。需要把结果返回网页时，发送前会显示接收网站，点击发送即可一并确认回传。
- 已连接网站的后续消息，可在扩展的「连接设置」里选择跟随网页设置、直接发送或先打开草稿。普通侧栏新对话默认使用「完全访问」，网页发起的对话默认使用「询问批准」。
- 内置浏览器从首页切到对话时，会保留已打开的网页和页面里填写的内容。地址栏平时简化显示，点击编辑可查看完整网址。也修复了首次打开网页失败、侧栏放大状态带到其他会话，以及开发者工具打不开的问题。
- Windows 安装版支持企业网页登录。部署方完成配置后，内置浏览器可自动处理受支持的企业登录，包括整页跳转和网页内嵌的登录窗口。

## 模型、插件与外部连接

- 语音设置现在共用一处麦克风选择和检测。「语音转文字」「语音对话」分别配置，「回复朗读」仍有独立设置。在线语音识别和合成支持兼容接口，可按服务配置协议、模型和音色。
- **MCP 连接配置支持导入和导出。** 可以选择文件或粘贴配置，兼容 Claude Code、Cursor、Cherry Studio 和 VS Code 的常见格式。预览后可勾选要导入的连接。新导入的连接默认关闭，导出时默认留空环境变量和请求头的值。
- 安装或更新插件后，相关界面会及时刷新，需要重启的情况更少。更新会保留已有的启停选择和兼容设置。全局和当前项目里有同名技能时，优先用项目里的版本。
- 文件无法在应用内预览时，可以用系统默认应用打开。在 Windows 上也可以临时选一个应用。在对话里的插件界面保存文件时，文件选择窗口会默认打开当前工作目录。也修复了应用刚启动时部分插件界面打不开的问题。
- 「外部连接」集中展示接入方式。外部会话有独立分组和更清楚的标题，也能在桌面看到实时运行状态。修复了 Python 客户端新建会话时未使用所选模型的问题。
- 新配置的外部 WebSocket 连接默认使用 `42960` 端口。已有配置继续使用保存的端口模式。如果端口冲突，可在「设置 → 外部连接 → 应用接入」里换一个端口，或改为自动分配。桌面应用可以照常启动。
- 内网服务的请求头可以填写固定值，也可以从登录信息映射字段。在通用设置的开发者区域可以查看当前加载的规则。修复了规则修改或登录信息刷新后，请求头未及时更新的问题。
- 改进了内置模型的登录错误提示。附加模型信息暂时取不到时，仍会显示已成功获取的模型列表。后台服务启动期间也可以查看和编辑视频模型设置。

## 存储、定时任务与故障排查

- **Windows 安装版可以更换数据目录（实验性）。** 在「设置 → 会话存储」选择一个空文件夹，即可迁移会话、插件和本地语音模型等数据。应用会在迁移时退出，正在执行的任务可能中断。迁移完成后，应用会自动重新打开。
- 「会话存储」可以查看各类数据占了多少空间，直接打开目录或复制路径。可以单独查看本地语音模型和升级备份的占用、删除升级备份，也可以清理浏览器缓存并保留网站登录状态。
- **会话诊断包包含更多排查资料。** 除了所选运行的日志和错误，还会收集可读取的会话上下文、模型调用记录和插件清单。关键错误集中放在一个日志文件里，更容易定位。分享诊断包前，请检查其中的任务内容和路径。
- 定时任务的运行历史和结果收件箱可以直接打开长期记忆整理的运行详情。即使这次运行没有生成对话，也能查看状态、开始和结束时间、耗时，以及已有的错误信息。
- 启动时如果无法分配足够的内存，会提示具体原因。Windows 升级也改进了安装路径和安装范围的检查，减少因选错升级目标而失败的情况。

## 更新后需要留意

- 如果使用 Chrome 扩展，请按应用里「浏览器」设置的指引更新配套扩展，再重启应用并在 Chrome 中重新加载扩展。
- 语音对话需要单独配置兼容的在线模型，本地语音识别和朗读模型无法用于实时交谈。普通录音在手动停止或达到时长上限后转成文字，会议分段录音入口已移除。
- 新版导出的模型配置会保留语音协议和音色，请用新版应用导入。上一版的密码加密配置仍可导入。旧语音配置如果缺少有效的协议或音色，可以在模型设置中补齐后继续使用。
