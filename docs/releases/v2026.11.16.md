# 更新说明

## 新增功能

- 新增对话内语音交谈，配置兼容的在线语音对话模型后，可沿用当前聊天上下文连续交谈，文字内容同步显示，并可控制麦克风、扬声器和结束对话。
- 新增桌面聊天错误自动重试，遇到部分工具错误、上下文超限等已支持的问题时，可在同一会话中尝试继续；可设置重试次数或关闭。
- 新增实验性数据目录迁移，Windows 安装版可在“会话存储”中选择空文件夹，将会话、插件及本地语音模型等数据迁至新位置。迁移需要退出应用，完成后重新启动，正在进行的任务可能中断。
- 新增业务网页首次连接确认，点击已接入网页的助手按钮后，可在浏览器扩展侧边栏中确认连接，无需预先登记网址。连接后先展示待确认草稿，发送消息与分享结果分别授权。
- 新增企业网页登录支持，部署方完成配置后，Windows 安装版内置浏览器可在受支持的企业登录跳转中自动完成认证并继续访问原页面。

## 功能改进

- 语音设置：统一麦克风选择与检测，将“语音转文字”和“语音对话”分开配置，回复朗读保留独立设置；完善兼容在线识别与合成接口，以及模型、协议和音色选择。
- 浏览器扩展：侧边聊天支持选择工作目录，直接回答助手提问；改进消息、思考过程、工具执行、折叠与滚动展示。
- 内置浏览器：统一标签页与导航体验，地址栏简化网址展示，编辑时可查看完整地址；从首页进入会话时保留已打开页面及其中的输入内容。
- 文件处理：不支持内置预览的文件提供“使用系统默认应用打开”入口，Windows 支持选择本次打开文件的应用；插件交互应用保存文件时默认定位当前工作目录。
- 会话存储：重新整理数据位置与空间占用展示，可打开或复制路径，单独查看本地语音模型和升级备份占用；支持删除升级备份及清理浏览器缓存，缓存清理保留登录状态。
- 插件管理：改进安装与更新流程，保留原有启停选择及兼容设置，更新后同步刷新相关界面，减少不必要的重启；同名技能优先使用当前项目中的版本。
- 外部客户端：统一外部连接入口和会话分组，改进会话标题，并修复 Python 客户端新建会话时未正确应用所选模型的问题。
- 内网服务接入：按已配置策略添加请求头时，支持字段映射和固定值，方便接入企业服务。

## 问题修复与稳定性

- 修复消息中带括号的网址识别不完整，以及重复显示相同工具失败提示的问题。
- 改进任务启动与恢复，减少聊天发送被恢复状态阻塞的情况；修复部分任务完成或多助手任务接入后工具不可用的问题。
- 修复内置浏览器首次导航异常、切换会话后侧边栏放大状态残留及开发者工具打开失败的问题。
- 改进插件交互应用的启动准备，减少后台服务尚未就绪时打开失败的情况。
- 修复服务请求头在策略调整或登录信息刷新后未正确生效的问题，完善内置模型登录凭据的错误提示。
- 后台服务尚未就绪时，仍可查看和编辑视频模型设置，已有配置和未保存内容不会因此隐藏。
- 改进 Windows 更新目标校验，减少安装位置与安装范围识别异常导致的失败。

## 更新注意事项

- 更新应用后，请按浏览器设置中的指引同步更新配套扩展，重启应用并重新加载扩展，以保持连接兼容。
- 语音对话需要单独配置兼容的在线对话模型，本地语音识别和朗读模型不提供此能力。普通录音在停止或达到时长上限后转写，不再提供会议分段录音模式。
- 模型配置导出会保留语音协议和音色信息，新导出文件需使用新版应用导入；仍支持导入上一版的密码加密配置。旧语音配置缺少有效协议或音色时，需要在模型设置中补全后使用。
