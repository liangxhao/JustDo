# v2026.8.26 更新说明

## 主要更新

- 新增可编辑文件预览，可直接在应用内查看、修改并安全保存任务生成的文件；当文件已在外部发生变化时会避免意外覆盖。
- 新增上下文占用环形指示器，更直观地展示当前会话的上下文使用情况；修复首次运行时占用可能短暂显示为 0 或无法及时恢复的问题。
- 结构化提问现支持配置等待时间和跳过方式，并改善默认“其他”选项、必填状态、焦点切换与答案保留行为。
- 新增用户 Chrome 扩展连接模式，完善连接测试、扩展状态验证和启动过程提示。
- 设置页整合到主窗口，扩展外观、自定义模型和 Agent 运行设置，并提供默认思考强度选项。

## 会话与任务执行

- 提升长时间任务的持续执行能力，减少任务在等待、上下文整理或多步骤处理期间意外结束的情况。
- 改进子任务协作与结果汇总，运行期间可实时展示子任务进度；即使完成通知后又产生后续子任务，或一次等待只返回部分结果，也会继续等待必要的子任务完成后再生成最终答复。
- 优化上下文整理过程的状态展示与异常恢复；整理期间会持续显示运行状态，整理失败后也能更可靠地继续会话。
- 修复模型切换在不同会话间相互影响的问题，并让会话标题、消息底部模型信息和实际使用模型保持一致。
- 增加模型响应等待提示，在响应延迟较长时提供更清晰的当前状态，同时减少重复或过早出现的等待警告。
- 改进流式消息、工具执行过程和进度摘要的展示，可恢复漏收的长时间等待工具及其后续状态，保持工具事件顺序，并避免运行中的工具被提前归入历史摘要。
- 优化任务中断后的消息保留和状态显示，使未完成的对话内容、运行结果和后续恢复更加清晰。
- 改进最近会话活动排序和会话切换恢复，后台会话仍会持续接收运行进度，重新进入时可恢复未完成消息、工具和整理状态，并减少闪烁、内容错位和旧状态短暂回显。

## 交互与界面

- 重新设计工作目录选择器，提升项目切换和路径选择体验。
- 回答结构化问题时可继续查看原会话内容，并优化浮动问题窗口在不同窗口尺寸下的布局。
- 改进斜杠命令的键盘选择高亮、执行计划卡片状态和过程摘要展开位置；运行时间线会区分进行中与已完成耗时，并可用行内或并排模式查看文件修改差异。
- 扩展外观设置并优化浅色主题配色，同时提升长会话缩略导航的点击和滚动可靠性。
- 调整侧边栏选中样式、设置导航和模型配置表单，使常用操作更集中、状态提示更明确。

## 浏览器与定时任务

- 提升用户 Chrome 扩展连接检测的稳定性，可更准确地区分扩展未连接、服务未启动和连接异常等状态。
- 优化定时任务卡片布局与编辑体验，点击对话框外部时不再意外关闭尚未保存的任务。
- 加强定时任务同步，能够更可靠地处理外部删除、重复删除和并发变更，并及时清理已不存在的任务。
- 控制定时任务日志体积，减少长期运行后无效日志持续累积。

## 内置能力与运行环境

- 更新内置图表设计和数据分析能力，补充更多图表、流程、架构和数据展示场景。
- 完善常用 Python 数据处理依赖的离线支持，减少首次执行数据分析任务时的额外准备；运行期间通过 pip 安装的包会保存到受管用户目录，应用升级后仍可继续使用。
- 升级任务运行环境并改进启动、恢复与日志处理，提升连续任务和复杂会话的整体可靠性。
