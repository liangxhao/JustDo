# v2026.8.10 更新说明

## 主要更新

- 新增持续目标执行能力，并提供安全的目标终止控制，让长时间任务的执行和管理更加可靠。
- 优化最近会话、会话分组和侧边栏交互，当前会话状态与分组标题更加清晰。
- 会话权限现在可以持久保存并即时生效，减少重复设置。
- 改进历史消息恢复、文档浏览设置及代码框线渲染，避免内容截断和排版错乱。
- 提升上下文压缩异常后的恢复能力，降低长对话中断风险。
- 完善定时任务对原生 cron 操作的支持。
- 提高内置 skills 更新和删除的可靠性，并扩充提示词目录。
- 优化 OpenClaw 运行参数、模型请求兼容性和请求用途标记。
- Windows 离线运行环境改用更精简的 MinGit，并修复内置 npm 运行问题。
- 精简重复资源和非必要构建文件，在保持完全离线使用的前提下显著减小安装包体积。
