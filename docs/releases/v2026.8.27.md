# v2026.8.27 更新说明

## 主要更新

- 新增可编辑文件预览，可直接在应用内查看、修改并安全保存任务生成的文件；当文件已在外部发生变化时会避免意外覆盖。
- 新增上下文占用环形指示器，更直观地展示当前会话的上下文使用情况。
- 会话详情新增主会话与所有 Subagent 的 Token 汇总，可分项查看输入、输出及缓存用量。
- 结构化提问现支持配置等待时间和跳过方式，回答时可继续查看原会话内容。
- 新增用户 Chrome 扩展连接模式，只共享指定标签页，并提供安装、配对和连接测试引导。
- 设置页整合到主窗口，扩展外观和自定义模型配置，常用设置更加集中。
- 新增 Agent 运行配置，可调整委派策略、Subagent 模型与并发参数，并设置默认思考强度。
- 目标任务现在支持配置自动续跑上限，便于在长任务的持续执行能力与资源消耗之间取得平衡。
- 聊天中的图片可双击在独立窗口中查看，支持缩放、拖动和复位。
- 软件更新支持按每天、每周或从不自动检查；发现新版本后由用户决定何时下载和重启安装。

## 会话与交互体验

- 提升长时间任务和上下文整理期间的持续执行能力，减少复杂任务意外结束的情况。
- 改进 Subagent 协作与结果汇总，可实时展示子任务进度，并在必要的子任务完成后再生成最终答复。
- 改进任务中断、会话切换和应用重启后的恢复体验，后台会话仍可持续接收进度，重新进入时可恢复未完成内容和运行状态。
- 完善会话级模型选择和模型响应等待提示，使会话标题、消息模型信息与实际使用模型保持一致。
- 优化流式消息、工具执行和过程摘要的展示，使任务执行过程更容易跟踪和回顾。
- 改进执行计划与运行时间线，可区分进行中与已完成耗时，并支持行内或并排查看文件修改差异。
- 重新设计工作目录选择器，提升项目切换和路径选择体验。
- 扩展外观设置并优化浅色主题、侧边栏、会话列表及长会话导航体验。
- 优化文件预览抽屉和 Markdown 阅读体验，浏览大量历史消息时滚动更加顺畅。

## 浏览器与定时任务

- 完善 Chrome 连接状态检测和失败诊断，可区分扩展未连接、本地服务未启动及配对异常；同时明确隔离浏览器的网络访问范围，并避免在任务运行期间切换浏览器模式。
- 优化定时任务卡片与编辑体验，加强外部删除和并发变更的同步，并控制长期运行产生的日志体积。

## 更新与安装

- 优化自动更新检查频率；错过计划时间会在下次启动后补查，检查版本本身不会自动下载更新。
- 优化 Windows 安装和升级速度、进度展示与失败诊断，并提升从旧版本升级时的兼容性。

## 内置能力与运行环境

- 更新内置图表设计和数据分析能力，补充更多图表、流程、架构和数据展示场景。
- 完善常用 Python 数据处理依赖的离线支持，并保留运行期间安装的用户包，应用升级后仍可继续使用。
- MCP 请求超时现可在运行配置中设置全局默认值，也可为单个 MCP Server 单独覆盖，减少慢速工具过早超时或长时间无响应的问题。
- 改进记忆搜索与索引在代理网络和自定义模型配置下的兼容性；手动重建索引时会重新计算已有内容。
- 升级任务运行环境，提升启动、恢复和复杂会话的整体可靠性。
