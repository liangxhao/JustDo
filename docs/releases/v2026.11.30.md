# 更新说明

## 对话与工作区

- **处理过程更易查看。** 桌面和 Chrome 侧栏统一了思考摘要与工具调用的折叠样式，可展开查看工具参数和执行结果。桌面会话失败后仍可查看已记录的工具详情。
- **长对话与回复恢复。** 改进了上下文过长、回复生成中断等可恢复错误的处理。修复了部分新对话的首条消息未显示，以及后续轮次耗时显示不准确的问题。
- **工作区与模型选择。** 「最近对话」可按时间或工作区分组。切换默认工作目录后，已有团队会话继续使用原目录。输入框中的模型菜单按供应商分组，模型设置保存更快。

## 浏览器与网页接入

- **Chrome 侧栏显示模式。** 在支持的 Chrome 版本中，可在「跟随当前网页」和「全局显示」之间切换。全局显示可在同一窗口切换标签页时保持对话可见。扩展的连接设置会显示扩展版本，以及随附该扩展的桌面应用版本。
- **网页发起的对话。** 获得相应授权后，业务网站可收到实际发送的消息正文，包括用户发送前编辑的内容。未发送的网页草稿可在侧栏找回，首条消息发送成功后，对话才会出现在会话列表中。刷新侧栏时，已有对话的历史更容易恢复。
- **浏览器操作录制。** 可在录制结束后检查页面的网络请求明细，并选择哪些明细随演示发送。内置浏览器的地址栏新增右键菜单。
- **定时任务浏览网页。** 更多助手定时任务可在已有权限范围内使用内置浏览器在后台执行。

## 插件与外部连接

- **MCP 应用。** 改进聊天内和侧栏视图的加载与恢复，减少重复加载和打开后停在加载状态的情况。
- **外部客户端的目标模式。** 支持目标模式的客户端可查询、设置和清除会话目标，并接收目标状态更新。
- **账号与设置。** 改进企业登录凭据续期，以及内置模型认证失败后的恢复和提示。在插件页保存语音工具的模型或音色后，新配置可直接生效。
