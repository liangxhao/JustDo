# 更新说明

## 新增功能

- 新增侧边栏，支持内置浏览器、终端、文件浏览、文件预览、修改审阅和侧边聊天。
  可同时打开多个标签页，边聊天边查看网页、文件和执行结果，也可将侧边栏拆出为独立窗口。
- 新增内置浏览器，可直接在软件内打开网页、搜索内容和预览本地 HTML 文件；支持页面缩放、最近访问记录和浏览器代理设置。
- 新增浏览器扩展侧边聊天，可在浏览网页时直接与助手对话，回复实时显示，并按来源整理会话。
- 新增流程图编辑器，可让助手生成图表后直接修改文字、图形和连线，支持保存源文件及导出 PNG、SVG，绘图无需连接公网服务。
- 新增对话内交互界面，支持直接操作插件提供的应用。安装相应文件插件后，可在软件内打开、编辑和导出表格等文件。
- 新增对话内网页嵌入，可直接查看网页和生成的交互页面，支持放大、固定和在侧边栏中查看。
- 新增消息中的本地文件链接，可点击文件引用，在侧边栏中打开对应的文件预览。
- 新增多助手协作与讨论，可让多个助手分工处理任务或围绕同一问题讨论，并查看各成员的进度、消息和汇总结果。
- 新增可视化工作流，可将复杂任务拆成有先后顺序的步骤，分配给不同助手，查看执行进度，并批量处理同类任务。
- 新增计划模式，可先查看并调整助手提出的执行计划，确认后在当前会话中继续执行。
- 新增会话内容搜索，可通过消息中的关键词查找历史会话。
- 新增会话复制、消息回退和分支对话，可保留已有内容，从选定位置继续尝试不同方案。
- 新增语音输入和回复朗读，支持本地及已配置的在线语音模型，可选择音色并试听。
- 新增视频生成配置，配置支持视频生成的模型后，可让助手生成视频。
- 新增命令行与外部客户端接入，可通过本机连接使用桌面助手，并在设置中复制接入命令和配置。
- 新增版本更新历史，可在软件内查看历次更新说明。

## 功能改进

- 聊天阅读：新增文档式消息布局，调整正文、代码块和深色主题样式；思考过程支持十行预览和展开，执行过程、上下文整理记录及消息中的折叠内容更容易查看。
- 工作区：会话列表支持拖动调整宽度；Windows 文件树新增复制、剪切、粘贴、重命名、新建文件夹和移至回收站等右键操作，可与资源管理器互通。
- 图表编辑：支持让助手直接修改当前打开的图表，无需重新打开文件。
- 助手设置：增加软件工程、代码审查、调研、产品设计、数据分析和文档写作六类职责预设，角色规则可编辑。
- 任务回顾：集中展示会话摘要、引用网页、相关文件和用量统计，可直接打开对应资料。
- 交互回答：支持在回复中展示可操作的卡片；优化提问、选项填写和操作确认的展示。
- 插件管理：重新整理插件中心，支持分类查找、安装、导入和更新；增加操作进度与状态反馈，支持编辑插件文本配置，可识别哪些服务提供交互界面。
- 模型设置：优化自定义模型、图像、语音和视频模型的配置，支持导入导出模型配置及设置自定义请求头。
- 浏览器设置：浏览器与应用可分别设置代理；可调整每个会话允许打开的浏览器标签页数量，并删除最近访问记录。内置浏览器支持后台执行，与同一浏览器配置的前台页面共用登录状态。
- 浏览器扩展：显示随软件提供的扩展版本和更新指引，方便与浏览器中已安装的扩展核对并完成更新。
- 语音设置：统一模型与音色选择，增加麦克风诊断和可编辑文本试听，未准备好本地模型时提供明确提示。
- 记忆管理：重新设计记忆页面，方便查看和管理助手记忆。
- 定时任务：优化任务分组、手动执行入口和结果展示，减少静默任务产生的打扰。
- 电脑控制：执行电脑操作时显示活动提示，方便了解助手当前是否正在操作。

## 问题修复与性能优化

- 加快常规启动，先打开工作区，再完成后台准备；减少首次发送消息、切换会话和等待回复显示的时间。
- 修复部分会话刷新后内容缺失、消息顺序异常及失败内容无法恢复的问题。
- 改进流式回复、长对话滚动及音视频附件播放，减少内容重复、显示跳动和媒体遗漏。
- 改进长任务续跑、停止操作和多助手任务交接，减少进度显示与实际执行不一致的情况。
- 改进模型切换，保留手动选择，并更清楚地显示请求失败原因；完善内网模型服务连接，减少新增自定义模型时不必要的重启。
- 改进长任务中的登录凭据刷新，减少执行中认证失效的问题。
- 改进浏览器扩展配对、自动连接和连接状态提示。
- 改进插件启停与配置保存，减少不必要的重启。
- 改进 Windows 安装、升级和首次启动的稳定性，完善旧版历史导入与备份提示，缩减安装包体积，并完善随安装包提供的离线资源。
