# 更新说明

## 对话与工作区

- **语音对话。** 配置兼容的在线模型后，点击输入框里的电话图标，即可在当前对话里和助手交谈，语音会同步显示为文字。会议分段录音入口已移除。
- **任务自动续跑。** 遇到可恢复的执行错误时，助手可在原会话重试。子任务完成后，目标模式能更可靠地继续执行。
- **导出对话。** 在会话列表中右键选择「导出对话」，可将仍可读取的历史消息保存为 OpenAI 兼容的 JSON 文件。

## 浏览器与网页接入

- **Chrome 扩展侧栏。** 各标签页保留各自的草稿。可以直接打开消息中的文件链接和助手交付的文件。请按「浏览器」设置中的指引更新扩展，再重启应用并在 Chrome 中重新加载扩展。
- **业务网页发起对话。** 首次使用须确认站点授权，发送前可查看和编辑网页附带的上下文。新对话默认使用「完全访问」。获准回传时，网站可收到首轮的最终回复和交付文件信息。
- **内置浏览器登录。** 支持手动保存和填充网站密码。Windows 安装版完成部署配置后，也支持企业网页登录。

## 插件与外部连接

- **MCP 配置导入与导出。** 支持选择文件或粘贴配置。导入的连接默认关闭，导出时默认留空环境变量和请求头的值。
- **MCP 应用文件预览。** 在支持的应用中，可直接在侧栏预览归档的 PDF、图片、音视频和文本。同一工作区文件匹配多个应用时，可在文件树中右键选择应用。
- **卸载时清理插件数据。** 卸载 Knowledge Wiki 等有可清理本地数据的插件时，可以一并永久删除插件保存的知识库、归档原件或缓存。此选项默认不勾选，保留的数据可在重新安装后使用。
- 新建外部 WebSocket 连接默认使用 `42960` 端口，可在「设置 → 外部连接 → 应用接入」修改。

## 存储与排查

- **更换数据目录（Windows 实验性功能）。** 在「设置 → 会话存储」中选择空文件夹即可迁移数据。迁移时应用会退出，正在执行的任务可能中断。
- 会话诊断包新增会话上下文、模型调用记录和插件清单。分享前请检查其中的任务内容和路径。
