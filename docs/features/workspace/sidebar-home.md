# 侧边栏首页

空侧边栏打开后以浏览器“新标签页”作为首页：顶部地址栏接收网址或搜索，下方提供工具、应用和最近访问。它沿用当前会话及工作区，不新建对话或自动执行应用。

## 新标签页的创建与关闭

- 首次显式打开空侧栏时创建一个空白浏览器标签；页签栏加号新增并选中另一个新标签页。
- 关闭最后一个标签会收起侧栏，不立即补建空页。重新打开已有内容或切换会话时复用原标签。
- 空白页只显示常规导航与菜单；打开真实网页后才出现录制、标注和注释，回到空白页时隐藏这些工具。

空白标签同样计入容量。每会话默认最多 20 个浏览器标签，可在浏览器设置调整为 1–50；调低上限不关闭旧页，只限制新建。工具和应用入口仍遵循各自原有容量与上下文限制，新会话只展示可用能力。

## 工具与布局

工具区提供审阅、终端、文件、侧边聊天和浏览器。布局按侧栏宽度响应：440px 起工具两列，更窄时单列；应用及最近访问对应四列/两列。工具高 40px，图标、文字和快捷键对齐，沿用主题 token，支持中英文、键盘焦点及长标题省略。

快捷键从用户设置读取；审阅没有现成快捷键，不显示占位。完整工作区的拆出与收回见[独立窗口](detached-workspace.md)。

## 应用目录：发现不等于执行

应用列表复用当前会话或首页已经验证的原生目录，没有可展示条目时隐藏。单一手动入口直接打开应用标签；多入口、设置、搜索和安装引导仍进入原有操作标签。文件入口继续由文件预览使用，不放入首页手动入口。

目录会自动预热，并保留加载、失败和显式重新读取。首次连接遇到 Gateway 明确启动拒绝时保持转圈及骨架，原始连接等待起最多 60 秒，重复拒绝不延长截止时间；普通连接失败和认证后的重连仍按 15 秒处理。真正超时或准备失败才显示失败及重读按钮，不要求用户为正常启动等待反复刷新。

图标先取入口 `icons`，再取服务 `icons`；接受目录内嵌图片及深浅主题版本。缺图或解码失败显示名称缩写，不请求公网图标、不读取本机图标文件。内置 draw.io 自行声明离线图标。显示目录和图标均不启动业务工具或发送模型消息；实际准入见[MCP Apps](../chat/mcp-apps.md)。

## 最近访问：读取、打开与删除

首页显示现有历史中最近四个不同 HTTP(S) 或本地文件页面，过滤带 URL 凭据的地址和临时预览页。每次首页打开时刷新，不后台轮询；加载、空列表和失败分别展示。首页隐藏或关闭后丢弃旧读取结果。

点击条目在当前会话内置浏览器打开；当前是新标签页时直接导航该空白标签，搜索沿用地址栏。文件缺标题时使用文件名并显示通用图标，不通过网络图标接口读取磁盘。

网页图标由 Main 返回已保存的 data URL；优先复用真实 guest 的 favicon，旧记录缺图时沿浏览器代理与 Cookie 补取。Renderer 不直接访问网站、CDN 或第三方图标服务，解码失败最多重试一次。缓存、请求取消与迟到写入的完整规则见[浏览器设置](../browser/browser-settings-design.md#浏览历史与站点图标)。

每项在悬停或键盘聚焦时显示删除按钮，触屏始终显示。删除使用历史接口，不触发导航；执行时阻止重复删除，失败保留条目和提示，成功后重读并补齐最多四项。删除历史同时删除对应图标；清缓存保留历史与来源地址，只清图像。
