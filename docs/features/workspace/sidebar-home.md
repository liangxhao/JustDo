# 侧边栏首页

浏览器标签页默认每个会话最多 20 个，包含空白“新标签页”。用户可在浏览器设置中
将上限调整为 1–50，保存后立即生效；调低上限保留已打开页面，只限制继续新建。

## 当前首页

侧边栏首页以“新标签页”呈现：首次打开空侧栏时自动创建一个浏览器空白标签，使用顶部地址栏输入网址或搜索，下面依次是工具、应用与最近访问。应用目录没有可展示条目时隐藏该区。页签栏加号直接新增并切换到另一个“新标签页”；工具为审阅、终端、文件、侧边聊天、浏览器，从页内选择，各入口沿用原有上下文与容量限制。新会话首页只展示可用能力。关闭最后一个标签时侧栏自动收起，不立即补建空页；以后显式打开空侧栏才创建新标签页。切换会话或重新展开已有内容的侧栏时复用原标签。

首页地址栏旁仅保留常规浏览器导航与菜单，录制、标注和注释入口在打开网页后显示；切回空白标签时隐藏相关工具与标注界面。

工具区使用侧栏宽度作为布局依据：440px 起两列，更窄时单列；应用和最近访问对应四列/两列。工具高度统一为 40px，图标、文字与快捷键对齐，使用已有主题 token，支持中英文、键盘焦点和长标题省略。快捷键取自用户设置；审阅没有现成快捷键，因此不显示占位提示。

应用列表从输入框“+”菜单移到首页，复用已验证的当前会话或首页原生目录。单一手动入口直接创建应用标签，多入口、设置、搜索与安装引导仍进入原有侧栏操作标签；文件入口继续由文件预览使用。首页目录保留加载、失败和显式重新读取，显示列表不执行应用或发送模型请求。图标读取插件经原生发现提供的入口 `icons`，缺省时读取服务 `icons`；支持随目录提供的内嵌图片及深浅主题版本，不请求公网图标或读取本地文件。缺图或解码失败使用应用名称缩写；内置 draw.io 自行声明离线图标。详见 [MCP Apps](../chat/mcp-apps.md)。

应用目录自动预热；首次连接遇到 Gateway 明确报告仍在启动时，保持加载转圈和骨架动画，等待就绪后自动显示列表，无需手动点击重新读取。该启动等待从原始连接等待开始最多 60 秒，重复启动拒绝不延长截止时间；普通连接失败和认证后的重连仍按 15 秒处理。真正超时或准备失败才显示失败提示及重新读取按钮。

最近访问使用现有浏览器历史，最多展示四个不同的 HTTP(S) 页面或本地文件页面，过滤带 URL 凭据的地址及临时预览页面，支持加载、空状态和失败提示；首页打开时刷新，不后台轮询。站点图标由 Main 按历史页面 URL 返回已保存的图片 data URL，优先复用真实 guest 已加载的 favicon。旧记录缺图时由 Main 沿浏览器代理和 Cookie 补取；解码失败最多重试一次网站 favicon，仍失败显示通用图标。主 Renderer 不直接请求网站、图标 CDN 或第三方图标服务；历史删除移除关联图片，缓存清理保留历史及来源地址但清除图片。详细规则见[浏览器设置](../browser/browser-settings-design.md)。本地文件条目使用文件名作为空标题的回退，使用通用图标，不请求网站 favicon。点击网页在当前会话的内置浏览器打开，浏览器新标签页则导航当前空白标签；搜索使用其原地址栏。

每个最近访问条目在悬停或键盘聚焦时显示删除按钮，触屏设备始终显示。删除沿用浏览器历史接口，移除对应页面的历史及关联图标，不触发页面导航；成功后重新读取历史，按最近访问顺序补齐最多四项。删除期间禁用重复删除；失败保留条目并显示提示。首页隐藏或关闭后，旧列表读取结果不再更新界面。

独立窗口见[完整侧边栏独立窗口](detached-workspace.md)。
