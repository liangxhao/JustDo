# 侧边栏首页

## 当前首页

侧边栏首页以“新标签页”呈现：首次打开空侧栏时自动创建一个浏览器空白标签，使用顶部地址栏输入网址或搜索，下面是工具与最近访问。页签栏加号直接新增并切换到另一个“新标签页”；工具为审阅、终端、文件、侧边聊天、浏览器，从页内选择，各入口沿用原有上下文与容量限制。新会话首页只展示可用能力。关闭所有标签且侧栏仍打开时恢复一页，切换会话或重新展开侧栏时复用已有标签。

首页地址栏旁仅保留常规浏览器导航与菜单，录制、标注和注释入口在打开网页后显示；切回空白标签时隐藏相关工具与标注界面。

工具区使用侧栏宽度作为布局依据：440px 起两列，更窄时单列；最近访问对应四列/两列。工具高度统一为 40px，图标、文字与快捷键对齐，使用已有主题 token，支持中英文、键盘焦点和长标题省略。快捷键取自用户设置；审阅没有现成快捷键，因此不显示占位提示。

最近访问使用现有浏览器历史，最多展示四个不同页面，支持加载、空状态和失败提示；首页打开时刷新，不后台轮询。站点图标优先使用网页声明并随历史保存的真实 favicon，旧记录或加载失败时尝试该站点的 `/favicon.ico`，仍失败则显示通用网页图标。图片请求不带 Referer，不依赖第三方图标查询服务；清理历史也会删除关联的图标 URL。点击网页在当前会话的内置浏览器打开，浏览器新标签页则导航当前空白标签；新标签页复用工具区和最近访问，搜索仍使用其原地址栏。

独立窗口见[完整侧边栏独立窗口](detached-workspace.md)。轻量“新建文档”仍属[后续候选设计](../../plans/openclaw-control-ui-adoption-plan.md#轻量文档创建候选)。
