# 侧边栏首页

## 当前首页

侧边栏首页以“新标签页”呈现：首次打开空侧栏时自动创建一个浏览器空白标签，使用顶部地址栏输入网址或搜索，下面是工具与最近访问。页签栏加号直接新增并切换到另一个“新标签页”；工具为审阅、终端、文件、侧边聊天、浏览器，从页内选择，各入口沿用原有上下文与容量限制。新会话首页只展示可用能力。关闭最后一个标签时侧栏自动收起，不立即补建空页；以后显式打开空侧栏才创建新标签页。切换会话或重新展开已有内容的侧栏时复用原标签。

首页地址栏旁仅保留常规浏览器导航与菜单，录制、标注和注释入口在打开网页后显示；切回空白标签时隐藏相关工具与标注界面。

工具区使用侧栏宽度作为布局依据：440px 起两列，更窄时单列；最近访问对应四列/两列。工具高度统一为 40px，图标、文字与快捷键对齐，使用已有主题 token，支持中英文、键盘焦点和长标题省略。快捷键取自用户设置；审阅没有现成快捷键，因此不显示占位提示。

最近访问使用现有浏览器历史，最多展示四个不同的 HTTP(S) 页面，支持加载、空状态和失败提示；首页打开时刷新，不后台轮询。站点图标由 Main 按历史页面 URL 返回已保存的图片 data URL，优先复用真实 guest 已加载的 favicon。旧记录缺图时由 Main 沿浏览器代理和 Cookie 补取；解码失败最多重试一次网站 favicon，仍失败显示通用图标。主 Renderer 不直接请求网站、图标 CDN 或第三方图标服务；历史删除移除关联图片，缓存清理保留历史及来源地址但清除图片。详细规则见[浏览器设置](../browser/browser-settings-design.md)。点击网页在当前会话的内置浏览器打开，浏览器新标签页则导航当前空白标签；搜索使用其原地址栏。

每个最近访问条目在悬停或键盘聚焦时显示删除按钮，触屏设备始终显示。删除沿用浏览器历史接口，移除对应页面的历史及关联图标，不触发页面导航；成功后重新读取历史，按最近访问顺序补齐最多四项。删除期间禁用重复删除；失败保留条目并显示提示。首页隐藏或关闭后，旧列表读取结果不再更新界面。

独立窗口见[完整侧边栏独立窗口](detached-workspace.md)。轻量“新建文档”仍属[后续候选设计](../../plans/openclaw-control-ui-adoption-plan.md#轻量文档创建候选)。
