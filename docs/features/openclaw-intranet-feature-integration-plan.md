## 目标与用户已确认的约束

在已经完成的 OpenClaw v2026.9.6 升级基础上，将适合公司内网使用的能力接入现有产品界面。
本轮按顺序实施三项：**技能提炼与审核 → 浏览器实时查看与人工介入 → 会话归档与存储管理**。
先完成每项的最小完整流程及验证，再推进下一项。

- 软件部署在公司内网。除浏览器可以访问公司外网外，应用、Gateway 和其他执行组件只能连接公司内网服务。
- 模型调用复用现有公司内网模型配置；不新增公网模型、外部账号或在线下载的运行时依赖。
- 浏览器可访问外网，不代表应用后台有公网访问能力，也不代表后台拥有浏览器中的登录身份。
- 公司 MCP 涉及内部身份与业务权限，没有确定的客户端接入规范；本轮不做 MCP 接入、登录或诊断改造。
- 不提取浏览器 Cookie、令牌或证书来替代正式的服务认证，不把浏览器作为后台请求的通用公网代理。
- 本计划约束新增功能的网络依赖，不授权顺带重构整个软件的网络策略或移除既有插件。

- 内网 MCP 的新增接入、认证、权限或诊断改造；现有能力保持原有职责。
- CLI Agent 选择器：尚未验证各 Agent 在公司环境中的模型、认证和运行依赖。
- 公网会话分享、远程云机器、FaceTime、会议实时语音、移动端、TypeSafe/ONNX 决策服务。
- 专家团队创建向导：作为后续候选，本轮不扩展现有 `agent-team` 或默认启用团队协作。
- 引擎自行更新机制、第二套 Control UI、与三项交付无关的基础设施重构。

## 通用实现与验证要求

- 遵循 Renderer/Main/Shared 边界，复用现有 Gateway 连接与订阅管理。确需新增 IPC 时完整更新类型、通道、handler、preload 和 Renderer 声明。
- 所有新增用户文本补齐中文和英文；使用产品元数据，不硬编码品牌。
- 写操作处理重复点击、超时后结果不确定和重连后的状态核对；不能用盲目重试造成重复执行。
- 功能不可用时展示原因，不能仅凭版本号启用一个调用必然失败的入口。
- 更新相应架构文档，至少核对 `07-plugin-system`、`10-data-storage`、`15-chat-rendering`；完成后回填本计划实际范围、接口和验证结果。
- 为真实风险编写行为测试：所属 Agent、审核写入、订阅释放、控制权状态、归档恢复、配置保持等；避免仅镜像实现的测试。
- 运行受影响测试；交付前完成 `npm run lint`、`npm run build`、`npm test`。按仓库要求恢复 Electron 原生模块 ABI。
- 如修改运行时补丁或裁剪流程，从锁定 pristine 包重建，并运行 patch proof 和 Gateway smoke；不得就地升级含历史补丁的 runtime。
- 测试使用隔离 HOME/状态/配置/工作区，不拿用户真实历史做破坏性归档验证。
- 没有可用公司模型、企业网页或真实账号时，完成可运行的自动测试与本地验证，列出真实环境待验项目，不能宣称端到端已通过。
