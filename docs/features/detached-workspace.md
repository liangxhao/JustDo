# 完整侧边栏独立窗口

侧边栏标题栏提供「在独立窗口中打开侧边栏」。打开后可把完整工具区拖到另一块
屏幕，主聊天区域展开。独立窗口包含原有 Tab、Tab 操作、文件路径栏和文件树；
包括 agent-team、Swarm Workflow、浏览器、终端、文件编辑、Review、侧聊、计划与子代理，
不使用可拆出 Tab 的白名单。

关闭独立窗口会把同一份工具区收回。独立时 Tab 栏隐藏拆出、全屏与关闭侧边栏按钮，
统一通过窗口标题栏控制窗口。拆出和收回保留
浏览器页面、未提交表单、终端、文件草稿以及聊天组件；不会创建新会话或新执行。
独立窗口跟随主窗口选中的会话，继续使用现有会话工具保留规则。
独立窗口的原生标题栏保持空白，不显示会话标题或应用名称。
独立窗口沿用主窗口的平台标题栏、圆角、边距与主题样式；Windows 使用相同的
自定义窗口按钮。最小化、最大化及系统菜单只操作独立窗口，关闭仍为收回侧边栏。
宠物始终留在主窗口，包括悬浮模式；通知仍跟随可见的工作区。
打开、收起、拆出侧边栏不改变宠物的位置或主窗口拖动范围。停靠原生视图中的
宠物仅是主窗口宠物在遮挡区域的同步投影，使用主窗口坐标，拆出后不再显示。
主窗口标题栏的侧边栏按钮可以重新显示独立窗口。
主题与外观设置同步到侧边栏；链接沿用主窗口的打开规则，聊天消息链接遵循
内置网页 Tab / Chrome 偏好，本地 HTML 保留会话目录上下文。
Tab 较多时的列表菜单也显示在工作区内，定位与键盘焦点跟随当前窗口。

最小化主窗口保留独立窗口。主窗口关闭到托盘会同时隐藏它，恢复主窗口时重新
显示；关闭独立窗口会收回并显示主窗口。窗口位置保存在产品配置中，屏幕断开
或工作区改变后限制在可用显示器范围内；没有旧版本窗口状态迁移。

主窗口出现执行审批、问题或其他阻塞弹层时，独立窗口显示返回主窗口的提示。
工作区自身的计划审批和工具对话框保留在工作区。普通通知或菜单不会被当作
执行审批，浏览器 guest 权限与原有停靠方式保持一致。

子文档意外销毁时会撤销旧窗口身份并重新打开，保留原先是否独立显示的选择。
这种异常会提示页面未保存内容可能丢失；普通关闭独立窗口仍是收回原文档。

## 实现和验证

源 React 树 portal 到固定的无 preload 文档，通过 Main 移动同一 WebContentsView。
生命周期和权限边界见 [进程模型](../architecture/03-process-model.md)，跨文档
渲染约定见 [聊天渲染](../architecture/15-chat-rendering.md)。

`node scripts/test/workspace-window-probe.cjs` 使用独立测试 profile，验证开发 HTTP
和文件 URL 两种模式下的实际 CoworkDisplayPanel、窗口 manager/IPC、React/Lit、
Monaco、xterm 和 browser guest。覆盖多次移动、原生关闭、草稿与表单保留、菜单、
合成中文 composition、主窗口最小化/隐藏/恢复、顶层审批以及 generation 撤销。
测试页使用生产 Tailwind 布局样式，追加覆盖 Tab 列表选择、焦点与窗口缩放。
主窗口最小化后，仅改变子文档内部尺寸，验证终端列数、Monaco 普通与 diff 编辑器、
Swarm 图形布局和聊天滚动继续更新；详情弹窗拖动与缩小窗口后保持可见。
小工作区用模拟显示器事件与真实原生窗口检查尺寸及最小尺寸约束。
追加验证独立窗口按钮的操作和状态、空标题、主题背景更新，以及侧边栏开关、
拆出和收回时宠物主节点与位置不变，停靠区的拖动使用主窗口坐标。
宠物可在停靠侧边栏与聊天区之间双向拖动；两种显示方式均验证主窗口四边的
拖动边界及标题栏区域，独立窗口不显示宠物，其指针输入不改变主窗口宠物位置。
还验证真实 TerminalPanel 在拆出/收回时没有重新创建或关闭，主窗口菜单遮挡时
通知返回主窗口，最小化后关闭到托盘，以及退出时独立窗口先关闭的清理顺序。
追加覆盖生产主题 CSS 的主题切换、停靠/分离时实际点击外链、两种显示状态下
子文档自关闭后的重新取得，以及失效 generation 的重复通知。进程退出分支用
事件注入验证；当前同源 workspace 与 Main 共享渲染进程，真实强制崩溃会同时影响二者。
测试不启动 Gateway，也不读取应用数据库。输出在忽略的 `.tmp/` 中。

物理双屏拖动、不同显示缩放、操作系统中文输入法、原生剪贴板和麦克风/系统音频
需要人工验收。合成 composition、编辑器程序输入及终端 paste 不能替代这些
设备测试。首次版本通过按钮操作，不包含拖动 Tab 拆出或多个独立侧边栏窗口。

计划与多轮独立评审、构建和测试结果见
[实施与验收记录](detached-workspace-plan.md#final-review-and-validation-record)。
Lint、构建、Main 类型检查及本功能回归通过；初次全量测试的四项原有失败及
后续 rebase 的验证范围分别记录在验收记录中。
