## 阅读方式与范围

本目录逐项定位核心、session 编码工具、工具搜索/Code Mode、仓库内插件工具以及 JustDo 自有扩展。字段列是源码的顶层索引，不是可直接调用的完整 JSON Schema：**类型、required、默认值、嵌套结构、enum 与 action 间约束必须点开所链 schema 查看**。多个 union 分支字段合并列出不意味着可以同时传入。optionalStringEnum 等辅助工厂会影响 required，故速查不以缺少问号表示必填。

“无直接 outputSchema”指这份注册对象未直接声明；不是返回任意值或没有结构。实际结果须追踪 execute、返回 details/content 及导入的返回类型。所有输出解析默认失败时保留原文，不据名称臆造结果。行号为本次源码快照的定位辅助。

清单按静态定义与注册入口核对，不承诺任意插件、MCP 服务或特定运行时的动态工具可被有限名单穷举；实际启用条件见主计划。测试/fixture、模型探测 ping、纯工具转发包装不计为新的业务工具。通话控制及 QA 工具另行标注。

本次列出 **168 个定义条目**（同名不同实现分别保留），另列 JustDo 扩展和动态来源。只证明定义位置，未逐个执行调用。

## 覆盖限制与实施前检查

- 表中 schema 名称是源码表达式；声明在导入文件时沿该工厂 import 继续定位。内联/动态项必须审阅整个 schema builder，不从速查列表构造工具调用。
- 上游插件及通话控制工具是可选表面，不承诺默认启用；qa_restart_wait/qa_restart_unsafe_probe 仅 QA，不计划产品专用渲染。
- 结果工厂未声明 outputSchema 的工具，适配前必须取得成功/失败/部分返回的脱敏样例并核对 execute 分支；未知结果保留原文。
- 目录不把第三方 MCP/插件的未来新增工具列为已覆盖。新来源先通用渲染，经契约验证才加入专用 renderer。
- 本次静态参数索引与核心返回分支核对已完成；全工具真实执行、完整会话有效目录抓取与跨平台 UI 验收未进行。
