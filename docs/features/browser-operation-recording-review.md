## 2026-09-22 合并提交后的再次审查

审查基线为 `b3eb23222`（相对 `b2134aa72`），由三个 Agent 分别检查 guest 采集、共享协议/历史、Renderer 生命周期；主 Agent 复核 Main lease、原生测试和整体验证，并对历史去重进行交叉审查。

本轮确认并修复：

- 密码框在首次交互前切换为明文时可能丢失密码身份：从属性变更旧值保留身份。
- 单独按修饰键生成 `Control+Control` 等伪步骤：忽略无实际按键的修饰键事件。
- 最后一次防抖滚动在停止/离开页面前丢失或晚于后续点击：在停止确认及后续动作前提交。
- 双击合并未比较 frame/Shadow 作用域，可能删除其他元素的点击；同时未删除被替换步骤的截图：按作用域匹配并清理孤立图片。
- 暂停/结束后的迟到观察事件仍可修改定稿：仅在录制及其结束确认排空阶段接收。
- 不同的纯演示消息在一分钟内因正文均为空而被误判重复：增加稳定步骤身份比较，兼容原始信封及卡片投影。
- 历史恢复将步骤相对时间归零：保留有限非负时间。
- 发送端对录制 JSON 中易被传输清洗的控制/格式字符使用 Unicode 转义，并在转义后计算长度及预算，减少同时发送标注时的长度失配；旧数据仍使用受限恢复，不放宽任意页面文本边界。
- 更新旧版原生 smoke 中与“仅密码脱敏”矛盾的 CVV/嵌入内容断言；补充 Main lease 的错误归属释放与窗口销毁/崩溃/导航释放回归。

验证记录：标准 `npm test` 的原生模块切换被正在运行的应用锁定，未关闭用户应用。改用 Electron 的 Node 模式执行全量 Vitest，494 文件、5,031 项通过，8 项跳过；另 5 文件的 32 项失败涉及替代运行环境及临时目录清理，随后在标准 Node 下重跑这 5 文件，110 项全部通过。这是分运行环境的覆盖验证，不是标准 `npm test` 一次全绿。两个隔离原生 smoke 均通过，不访问用户 profile、Gateway 或业务网页。

全部修改完成后，标准 Node 下的浏览器、录制、Tab、历史和发送专项回归为 52 文件、950 项通过；生产构建（含 TypeScript 与 Electron bundle）、全量 ESLint 及 diff check 通过，两个原生 smoke 再次通过。构建体积提示及测试 fixture 的 Electron CSP/Mojo 警告仍存在，不作为业务链路验证成功的替代。

仍建议补充的能力（本轮未擅自扩大范围）：停止前带时限的末帧截图排空；真实重启后的卡片、图片、历史编辑重发端到端测试；长输入的状态摘要截断提示。跨域 frame、closed Shadow DOM、Canvas/自定义拖拽和慢于 450ms 的异步结果仍不保证完整采集。快速点击后立刻停止可能没有末步截图；截图为尽力采集，不是每一步的完整视频证据。相同演示和相同正文在一分钟内重复发送，仍受现有通用预显示时间窗口匹配策略影响。

## 2026-09-22 实测后的策略调整

用户实测为 14 步 / 3 页面 / 0 截图，随后明确要求仅密码脱敏。以下首轮审查中的验证码、支付字段及嵌入内容整页拒绝策略已被替换：仅可识别密码字段隐藏；普通查询参数和 fragment 保留；iframe/canvas/video 不阻止截图；隐藏登录框允许截图，密码相关 DOM 变化仍使在途截图失效。编辑页新增精简 HTML/层级选择器与逐步截图失败原因。URL 形式的过渡标题也使用密码参数清洗，导航不继承前一页标题。

`node scripts/browser-recording-smoke.cjs` 使用独立临时 profile 和本地测试网页，验证 sandbox guest 的原生截图、可信点击/HTML、动态页面、普通 URL 参数保留及可见/已显示密码的截图保护；不会操作用户正在运行的应用或会话。图片仍为可视区域截图，不包含元素局部裁剪。详见最新[采集策略](browser-operation-recording.md)。

审查范围：`feat/browser-operation-recording` worktree 中的全部未提交实现，包括 guest 采集、Main 互斥、Renderer controller、编辑 Tab、Composer、历史恢复及测试。三个 Agent 分域审查，主 Agent 负责整合；修复后对 UI 与录制生命周期进行交叉复查。

## 保留的边界

- 字段识别和截图检查不是完整 DLP。普通 DOM 元素的 closed shadow root 无法通过标准 DOM API 检测；页面普通文本或图片也可能包含私密信息。仍须在发送前人工检查步骤和图片。
- 跨域 iframe、复杂拖拽、系统对话框等不保证完整采集；本功能提供演示上下文，不是确定性重放或模型训练。
- 首轮全量测试中的 `provider-secret-file` 一项和 `reset-display-history` 四项失败已在原工作区复现，与本功能无关；同步 `dev` 后消除。未为通过测试修改共享 OpenClaw runtime 或历史补丁兼容逻辑。
- 未在用户真实业务站点上执行模型复现。功能已建立本地提交并合入最新 `dev`，尚未合回 `dev` 或推送远端。
