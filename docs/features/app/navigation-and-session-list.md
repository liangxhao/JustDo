# 应用导航、会话列表与设置外壳

本文维护主窗口导航、会话列表的加载/选择规则及设置页的交互边界。它们使用产品元数据和界面偏好，不拥有原生消息或执行终态。进程与启动的所有权见[系统架构](../../architecture/02-architecture.md)，首次准备与引擎准入见[启动与历史升级](startup-and-history-upgrade.md)。右侧工作区的新标签首页另见[侧边栏首页](../workspace/sidebar-home.md)。

## 主窗口导航与会话列表

应用外壳的左侧功能导航为 44px 图标栏，顶部固定为主页、定时任务、插件与更多，账号头像和设置齿轮位于底部。头像通过 preload 发起 Main 拥有的登录流程，账号菜单以 Portal 展示，避免被外壳裁切。主页显示独立的聊天列表面板（新聊天、搜索与已有会话）；切换到其他功能或收起聊天列表后，图标栏与账号入口仍保留。记忆及已启用的 Workboard 从更多进入，可逐项固定或取消固定，固定入口排列在更多之后。侧边栏偏好通过既有 ConfigService / preload Store 保存为 `app_config.sidebarPinnedItems`，只持久化功能 ID 与顺序；Workboard 暂时不可用时隐藏入口但保留固定偏好，不复制插件配置或聊天历史。

### 目录、摘要与分组加载

会话侧栏使用两层产品元数据：完整轻量目录保留会话 ID、来源、归组、状态、原生定位及活动时间，服务计数、存在性与后台运行发现；标题和历史绑定展示摘要按当前展开范围批量读取，每次 IPC 最多 200 个 ID。目录仍为 O(N) 查询，但不加载标题、正文，也不逐条读取会话详情或检查工作目录。桌面目录、摘要和全局搜索按父会话关系排除子会话映射。用户在[子智能体详情](../assistants/profiles-and-subagents.md#原生-subagent)查看和续聊子会话。首屏和加载更多使用本地目录与摘要。

「最近对话」标题右侧的时钟和打开的文件夹按钮用于切换时间或工作区视图，默认按时间。选择通过 `rendererPreferences` 保存在 Main KV，重启后恢复。置顶是标题上方的独立区块，手动组和来源组沿用各自的展开及分页状态。工作区按会话已保存的目录归组，同名目录展示路径，缺少目录的会话归入「未设置工作区」。工作区视图默认展开当前会话所在组，找不到时展开最近活跃的工作区。

展开工作区后，按最近活动从轻量目录挑选最多 20 个原始 ID，批量查询一次摘要，再按桌面侧栏的可见性规则展示。筛选后不足 20 条时直接展示结果，包括整批未命中的情况。每次点「展示更多」只查询下一批原始会话，已经取过的原始 ID（包括被筛掉的行）均计入分页。分组数量为可展示的会话总数，是否还能翻页根据原始候选决定。工作区组复用日期和其他分组的页脚、加载和重试样式。折叠及切换分组方式保留已加载页。

后台活动把可见会话带入已展开工作区的前 20 条原始记录时，按需读取该会话尚未加载的摘要。

置顶、今天、昨天默认展开并读取该范围全部摘要；其他时间组、手动组及 External、Chrome 来源组首次展开取前 20 条，继续每次最多追加 20 条，过滤后允许不足 20。分组总数来自完整目录，手动组保留创建与移动；来源组按真实入口固定归属，禁止手动迁入迁出。折叠保留已加载前缀；组内失败保留已有行并允许重试。全选与批量删除只覆盖当前展开且已显示的行。日期仍按本地日历和最近活跃时间分组，团队锚点先聚合完整目录中成员的活动时间再计数和选择前缀。

### 会话标题

桌面新建普通会话或 Worktree 会话时，把初始标题作为 `sessions.create.displayName` 交给 OpenClaw。
首轮准入确认后，后台生成的标题通过 Main 更新原生 `displayName`，再更新产品侧栏摘要。
手动改名走同一保存流程。自动结果绑定最初准备的原生会话 ID、生命周期版本和原始标题。
手动改名优先，已重置或替换的会话不会收到旧结果。

Agent 可用 `sessions_list` 读取或搜索可见会话的标题。`displayName` 可以重名，原生 `label` 保留原有显示优先级。
应用直接管理的会话在原生写入得到确认后更新侧栏，未能确认的手动改名会提示失败。
外部或借用会话的标题继续保存在产品侧。已有桌面会话在手动改名时同步，启动时不扫描或批量改写历史标题。

### 自动来源组与手动组

自动来源分组为 `Chrome` 和 `External`，中英文界面统一使用这两个英文名称。`Chrome` 对应
`source: chrome-extension`，`External` 汇总 `external.origin: cli` 的 CLI、ACP 和通用 app-server 会话。
历史外部映射保留原来源，按常规目录展示，不自动归入 External 或新增专用来源组。
内部来源标识不随显示名改变，会话标题旁不再重复显示外部来源小标签。
网页发起的 Chrome 草稿只在侧栏可用。桌面目录和搜索在原生确认接收首条消息后显示该会话。

外部会话的运行指示来自 Gateway 活动观测和当前进程仍在处理的外部执行请求。连接暂不可用时保留最近确认的活动。
引擎确认空闲且外部客户端没有正在准备或执行的任务时，旧回执仍未结算的会话停止转圈。
会话详情和诊断页显示「已结束」，表示会话当前无活动。执行结果仍由该轮回执提供。

两组都不属于可编辑的手动分组：会话项不提供移动菜单和拖拽，来源组不接收拖放。Main 按持久化来源拒绝这些会话的手动归组请求，并且仅允许普通会话移入真实存在的手动组或移出至未分组。普通用户组即使名为 Chrome 或 External 也保持可编辑；移动失败时界面不得改变归属。不提供历史客户端专用分组或来源转换；接入边界见[CLI / ACP](../external-clients/agent-cli.md)与[扩展侧栏](../../plugins/chrome-extensions/chrome-assistant/side-panel.md)。

### 搜索与后台存在性

分页摘要不能充当完整存在性证据：未读裁剪、后台标签及浏览器资源保留、idle 旧会话运行发现使用完整目录。搜索弹窗打开时独立读取完整简单摘要快照，按产品可见性确定范围，正文继续走原生 sessions.search；该快照不灌入侧栏摘要集合。未加载历史记录不得因侧栏折叠而退出搜索或后台发现。

### 导出对话

会话列表右键「导出对话」直接打开该会话的导出选项。选定保存位置后，Main 使用已连接的
Gateway 按原生会话身份逐页读取仍可访问的对话历史，并按时间顺序写入一份 OpenAI 兼容 JSON。
默认附带同一批可公开读取消息的原始字段。历史页和输出按需暂存，生成完整文件并校验来源后才替换目标文件；
导出文件不经过通用文本保存接口的大小限制。
连接或原生历史在读取期间发生变化、分页失败或必要的内容补取失败时，显示错误且不发布文件。

### 宽度与界面偏好

聊天列表与消息区之间的分隔线支持左右拖动及键盘左右、Home/End 调整。列表默认 240px，可在 180–480px 内调整，同时为消息区保留至少 320px；窗口空间不足时优先收敛列表宽度，恢复空间后回到用户选择的宽度。宽度通过 `rendererPreferences` 的 `shell.session-list-width` 保存到 Main KV，在下次启动及设置页返回时恢复；窗口缩放不覆盖已保存宽度。拖动结束、取消、失焦、收起列表、切换功能或卸载均释放拖动状态。

### 窗口标题栏与引擎提示

主界面的窗口标题栏由应用外壳统一渲染，从左侧图标栏右边贯穿聊天列表与页面内容，窗口控制按钮位于最右侧。图标栏保持全高；聊天列表和各功能页面位于标题栏下方，页面切换、列表收起及聊天加载不再各自创建窗口控制按钮。设置页和初始化／错误界面保留各自独立的标题栏。“打开 Control UI”入口位于“设置 → 通用”的开发者区域，在 Control UI 设置下方随其草稿开关显示，保存生效后可用；主界面更多菜单不提供此入口。

主界面与设置页的 AI 引擎提示位于标题栏右侧、最小化按钮左边，按启动、重启、失败（查看原因）和未启动（启动按钮）四种展示；运行时隐藏。状态由 Main 提供，失败原因弹窗挂载主文档，避免标题栏裁切。该提示不属于右下角通知栈，不能覆盖设置页底部操作；详见[执行引擎](../../architecture/05-agent-engine.md)。

## 设置页导航与草稿

设置使用独立滚动的分组侧栏与居中内容区，按用户要调整的对象分为个人偏好、模型与助手、任务执行、连接与集成、应用管理。个人偏好包含通用、外观、快捷键、语音和宠物；模型与助手管理模型来源与助手身份；任务执行包含执行设置、沙箱与隔离、Worktree、浏览器和电脑操控；连接与集成提供外部连接和消息通道；应用管理提供并列的使用统计、会话存储、关于与帮助，不再使用用量与存储合并页或页内切换。浏览器和电脑操控是助手执行任务的能力，外部工具委派与消息接入属于连接设置。

使用统计与会话存储保留独立页面身份 `usage` / `storage`；两页底部只显示关闭，不触发全局保存，表单 Enter 也不会保存其他设置草稿。会话存储按数据位置与按需空间统计、原生会话历史、归档策略组织。数据目录信息由 Main 提供，与 Gateway 状态独立；原生历史及归档管理仍由所属 Gateway 接口负责。归档策略在本区单独保存，不能把页脚关闭或全局保存解释为策略提交。

`settingsCatalog.ts` 声明页面身份、分组、翻译检索词和内容宽度；`SettingsNavigation` 仅负责搜索和导航展示，搜索匹配页面名称、说明与设置关键词，不挂载隐藏页面或读取配置。选择结果仍交由 `Settings.tsx` 执行离开保护和页面切换。`Settings.tsx` 继续持有配置草稿、预览回滚与保存流程，各领域页面保留原有即时保存或统一保存语义；界面重构不改变 Main/IPC 的持久化边界。通用页标题累计点击 10 次后，直接显示带统一边框的开发者区域，包含 Control UI、应用代理与 Gateway 端口，不再提供开发者模式总开关；离开通用页会重置显示计数，但保留本次设置草稿。

开发者区域还提供[全局出站请求头策略](../network/outbound-headers.md#查看应用当前加载的策略)的只读查看入口，展开后即可使用。

执行设置页按 Agent、侧栏标签页、Goal 模式、Code Mode、MCP、SubAgent 和 Swarm 分组展示参数，保留各分组的适用范围、实验性标识与行为说明；所有分组始终展开，不通过分类切换或折叠隐藏设置。配置草稿仍由父级持有。

## 实现入口与验证范围

外壳和侧栏实现位于 `src/renderer/app/shell/`、`src/renderer/features/cowork/components/sessions/` 与所属组件；设置目录、检索与草稿由 `src/renderer/features/settings/` 负责。完整目录和有界摘要的 Main 查询见[数据存储](../../architecture/10-data-storage.md#会话目录与按需摘要查询)，IPC 与 preload 仍按所属领域注册。

修改时核对折叠后的后台发现和全文搜索、来源组移动拒绝、摘要迟到、列表宽度恢复、账号菜单遮挡及设置离开保护。文中的交互约束不代表所有窗口尺寸或真实账号环境已经验收。
