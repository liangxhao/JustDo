# Chrome Assistant

Chrome Assistant 随桌面应用交付。用户可在 Chrome 侧栏对话、授权附带当前页上下文，或让助手操作已授权共享的标签页。使用侧栏和网页入口时，请保持桌面应用运行。

## 安装或更新扩展

1. 在桌面应用打开 **设置 → 浏览器**，找到 **Chrome 扩展** 区域。
2. 点 **打开扩展管理页**。把复制的地址粘贴到 Chrome 地址栏，打开管理页后开启 **开发者模式**。
3. 回到桌面应用，点 **打开扩展文件夹**。将打开目录中的 `chrome-extension` 子目录拖入 Chrome 扩展管理页。该子目录内有 `manifest.json`。
4. 在 Chrome 右上角的扩展菜单找到与桌面应用同名的扩展。点图钉可将扩展固定到工具栏。

网页 SDK 与 `manifest.json` 位于同一子目录。Windows 安装版的路径为 `<安装目录>/resources/chrome-extension/chrome-extension/chrome-assistant.js`。复制脚本和绑定业务按钮的步骤见[网页 SDK 接入](website-sdk.md)。

桌面应用显示随应用附带的扩展版本。Chrome 当前加载的版本在扩展管理页的 **详情 → 版本** 中查看。升级后若无法连接，先重启桌面应用并在 Chrome 中重新加载扩展。仍无法连接时，移除旧扩展，再从当前应用附带的目录安装。

## 侧栏对话、附件与审批

点 Chrome 工具栏中的扩展图标打开侧栏。侧栏支持文本、图片、文档、可选的网页上下文以及原生命令和实验插件审批。发送图片需要支持图片输入的模型。具体的附件限制、审批选项和问答行为见[侧栏对话](side-panel.md)。

关闭侧栏会断开查看并撤回侧栏中的待处理审批，已接纳的运行可以继续。重新打开后，扩展根据同一运行的状态与原生历史恢复显示。发送结果不明时，扩展保留未知状态供用户核对。

<a id="launch-conversations-from-a-website"></a>

## 业务网页发起对话

网站可使用随包 SDK 绑定自己的按钮。首次连接时，扩展显示网站来源并请用户授权。授权后，原请求进入待确认草稿，发送和结果分享由用户分别决定。开发者可按[网页 SDK 接入](website-sdk.md)获取脚本、运行示例并处理结果。网站权限和运行边界见[网页发起对话与结果分享](website-launch.md)。

## 宿主与版本

扩展负责侧栏、设置、网页上下文和自动化连接。桌面应用负责本机实例发现、会话、权限与执行。Chrome 通过扩展管理页加载组装后的扩展。扩展的显示名称来自应用品牌配置，固定公钥决定扩展 ID。

请配套使用桌面应用和扩展。Native Messaging 握手使用版本 2，app-server 实例发现要求协议版本 4。源码组装和发布入口见[宿主集成](integration.md)，发现和鉴权条件见[宿主接入要求](protocol-contract.md)。
