# 受管在线语音合成

本插件的 Speech provider 为宿主回复朗读和其它 provider 的显式委托提供统一协议实现。配置明确声明服务端点、模型、音色选择和经原生准备的 SecretRef；宿主发布的选择还显式声明协议。原始配置、解析后配置和底层合成都要求有效模型与音色，不按供应商名称、模型前缀或域名切换行为，不补公共端点、模型、音色或环境凭据。

| 合同 | 请求 | 当前响应 |
| --- | --- | --- |
| `openai-speech-http` | `/audio/speech` JSON，包含 input/model/voice 和受支持的格式等参数 | 完整音频字节 |

协议编解码复用纯 `speech-protocols` SDK，只实现标准 Speech 请求与二进制响应。音色保存为 `{kind: 'preset', voiceId}`，由用户提供有效 ID，不省略或猜测默认音色。未知协议、废弃兼容字段和默认音色配置拒绝执行，不清洗为缺字段后恢复标准默认；克隆或音色设计尚未接入。

插件不提供固定在线模型或音色目录，也不按模型名称决定是否发送受支持参数。模型和音色只校验标识格式，实际支持范围由所配置服务决定；缺失或非法标识在发送前拒绝。TTS 正文允许换行，标识的控制字符限制不套用于正文。

请求使用已配置 origin 的原生 HTTP／SSRF 策略，拒绝重定向，完整响应有大小与超时边界。当前不消费 SSE 或逐块播放；停止宿主播放不宣称远端合成已中止。工具 provider 的公开注册表委托不改变其自身启停、身份和偏好归属。

包内 `tests/speech-http.test.ts` 与纯协议测试验证标准请求、二进制响应、音色和废弃配置零发送；原生 schema/provider 集成另由宿主测试。合成端点验证不证明真实内网模型、设备、代理或最终分发产物已验收。

[原生 SDK 探针](../tts-local-cli/synthesis.md#分发与验证)使用随机端口本机 HTTP 服务，通过已注册的本 provider 和 TTS 工具委托验证标准 Speech 合成；期望请求独立手写，检查实际路径、方法、模型、音色及返回字节。它覆盖无环境凭据回退、废弃配置零请求、错误 HTTP、超时断链和跨 origin 重定向零请求；不模拟 SDK 网络层，也不调用公共模型。短音频 fixture 不代表编解码、音质、播放设备或实际内网部署已验收。
