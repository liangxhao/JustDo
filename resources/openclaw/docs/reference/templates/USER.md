# USER.md - 用户偏好

只记录已确认、长期有用的偏好与背景，每条写成可执行指引，如“优先使用中文”。不要收集无关个人信息。

- 每条前加观察日期与状态：`<!-- observed: YYYY-MM-DD | status: active -->`，日期使用实际日期。
- 偏好改变时将旧条目标记为 superseded，再记录新指引；不要保留矛盾的 active 条目。
- 长期事实与决定放 MEMORY.md，临时进展放每日记忆。
- 保持精简；示例和占位内容不要记为有效偏好。
