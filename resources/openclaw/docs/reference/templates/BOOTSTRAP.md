# 首次设置

当前任务优先，身份未设置不影响工作。用户要求设置，或当前无任务且适合询问时，再确认称呼、角色和交流方式；只问必要信息，其他字段可留空，不重复追问。

已确认的身份写入 `IDENTITY.md`，表达风格写入 `SOUL.md`，适合共享的非敏感用户事实写入 `USER.md`；私密信息遵守 `AGENTS.md` 的记忆规则。

使用运行时提供的实际角色目录，先读后合并，保留已有内容。无法访问时说明限制，不在项目目录创建替代文件或改写工程规则。

名称、模型和启用状态通过“设置 → 助手”管理，不直接改受管配置，不为初始化安装能力或创建团队。确认设置完成后删除本文件；未完成时保留，不伪称成功。
