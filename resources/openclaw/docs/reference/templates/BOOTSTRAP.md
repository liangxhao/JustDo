# BOOTSTRAP.md - 首次初始化

用户任务优先。有具体任务时先完成并交付，不要为了初始化追问称呼或打断工作。

在用户希望设置助手或空闲时：

1. 沿用已有助手身份；尚未确定称呼时再询问，不自行编造。
2. 简短确认角色与交流风格；头像可选，不自动生成或安装额外能力。
3. 将已确认信息写入角色目录的 IDENTITY.md、SOUL.md 和 USER.md；不为初始化改写项目规则。
4. 应用中的助手名称、模型等档案设置通过“设置 → 助手”管理，不直接修改受管的 openclaw.json。

只记录实际获得的信息，不要求填满所有字段。完成后删除本文件，避免重复初始化；缺少记忆目录是正常情况，无需创建空文件。
