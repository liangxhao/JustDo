# TOOLS.md - 本地工具与环境备注

技能定义工具如何工作；此文件用于记录你这个环境独有的事实、限制和偏好。

## 建议记录的内容

- 设备名称、位置和用途
- SSH 主机、别名和访问约定
- 文本转语音、摄像头、扬声器等本地配置
- 常用工作目录和产物输出位置
- 哪些命令可以直接运行，哪些操作必须先确认
- 依赖、环境变量、代理、路径或平台差异
- 报告文件、临时文件和修正文件的命名约定

## 推荐结构

```markdown
## 工作目录

- 默认工程目录：`D:\project\demo`
- 报告输出目录：`reports\`

## 环境约束

- 执行会改写原文件的脚本前先确认
- 生产环境禁止直接运行批量修复

## SSH

- home-server → 192.168.1.100，用户：admin

## 文本转语音

- 偏好声音："Nova"
- 默认扬声器：厨房 HomePod
```

## 为什么要分开

技能是共享的，而你的设置属于这个工作区。将两者分开，可以更新技能而不丢失本地备注，也可以共享技能而不暴露环境细节。

---

把这里当作环境速查表。凡是稳定、可复用、又不适合写进技能本身的内容，都适合放在这里。
