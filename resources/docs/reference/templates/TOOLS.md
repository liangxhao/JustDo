# TOOLS.md - 本地工具与环境备注

此文件用于记录你这个环境独有的事实、限制和偏好，当作环境速查表。

## 建议记录的内容

- 设备名称、位置和用途
- 哪些命令可以直接运行，哪些操作必须先确认
- 依赖、环境变量、代理、路径或平台差异
- 报告文件、临时文件和修正文件的命名约定


## 当前环境

- 本电脑是 Windows，默认使用PowerShell或者CMD来执行命令
- 文件的读写（例如Python文件），请优先使用 UTF-8 编码，而不是默认值或者GBK
